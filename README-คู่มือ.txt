===============================================
           คู่มือการใช้งาน CareerLens APP
===============================================

โปรแกรม CareerLens APP คือระบบจัดเก็บข้อมูลบุคลากร,
ข้อมูลเส้นทางอาชีพ (Career Path) และสามารถสร้างไฟล์
PowerPoint รายงานผลแบบอัตโนมัติได้ทันที

เวอร์ชันนี้เป็นแบบ Portable ผู้ใช้งานไม่ต้องติดตั้งโปรแกรมใดๆ
เพียงแค่เปิดไฟล์ run.cmd ก็สามารถใช้งานได้ทันที


-----------------------------------------------
1) โครงสร้างโฟลเดอร์ของโปรแกรม
-----------------------------------------------

CareerLens APP
│  Run.cmd              ไฟล์สำหรับเปิดโปรแกรม
│
└─ app
    ├─ app.js           ตัวโปรแกรมหลัก (Node.js)
    ├─ node.exe         ตัวรัน Node แบบพกพา
    ├─ node_modules     ไลบรารีจำเป็นสำหรับระบบ
    ├─ data
    │     database.sqlite   ฐานข้อมูลทั้งหมด
    │
    ├─ uploads
    │     Picture1.png      ไฟล์รูปพื้นฐาน
    │     (และรูปภาพผู้ใช้งาน)
    │
    ├─ public              ไฟล์ HTML, CSS, JS สำหรับ UI หน้าเว็บ
    └─ routes              ส่วนจัดการ API


-----------------------------------------------
2) วิธีเปิดใช้งานโปรแกรม
-----------------------------------------------

1. แตกไฟล์ ZIP ออกให้เรียบร้อย
2. ดับเบิลคลิกไฟล์:  Run.cmd
3. โปรแกรมจะ:
   - ตรวจสอบโฟลเดอร์ที่จำเป็น
   - โหลดฐานข้อมูล
   - เปิดหน้าเว็บให้อัตโนมัติ
4. จากนั้นหน้าเว็บจะเปิดขึ้นทันทีที่:
   http://localhost:3000

# เมื่อต้องการเลิกใช้งานโปรแกรมก็แค่ออกจาก cmd จากนั้น localhost จะปิดการใช้งานทันที
# หากต้องการใช้งานใหม่ ก็ให้เปิดไฟล์  Run.cmd ขึ้นมาเหมือนเดิม


-----------------------------------------------
3) ฟังก์ชันหลักภายในระบบ
-----------------------------------------------

(1) จัดการข้อมูล Incumbent (ข้อมูลพนักงานปัจจุบัน)
    - เพิ่มข้อมูล
    - แก้ไขข้อมูล
    - ลบข้อมูล
    - อัปโหลด/บีบอัดภาพอัตโนมัติ
    - สร้างรายงาน PowerPoint แบบอัตโนมัติ

(2) จัดการข้อมูล Successor (ผู้สืบทอดตำแหน่ง)
    - เพิ่มข้อมูล
    - แก้ไขข้อมูล
    - ลบข้อมูล
    - อัปโหลด/บีบอัดภาพอัตโนมัติ
    - สร้างรายงาน PowerPoint แบบอัตโนมัติ

(3) ระบบเก็บข้อมูล
    - ข้อมูลทั้งหมดถูกเก็บในไฟล์เดียว:
          app/data/database.sqlite
    - ผู้ใช้คนต่อไปจะเห็นข้อมูลที่เพิ่มไว้ก่อนหน้า

(4) อัปโหลดภาพอัตโนมัติ
    - เมื่ออัปโหลดรูป ระบบจะบีบอัดให้อัตโนมัติ
    - ลดขนาดเพื่อให้ฐานข้อมูลทำงานเร็วขึ้น


-----------------------------------------------
4) การกู้คืนหรือย้ายเครื่องอื่น
-----------------------------------------------

การย้ายโปรแกรมไปคอมเครื่องอื่นให้ทำตามนี้:

1. คัดลอกโฟลเดอร์ CareerLens APP ทั้งโฟลเดอร์
2. วางลงในคอมเครื่องใหม่
3. รันไฟล์ run.cmd ทันทีใช้งานได้เลย

ข้อมูลทั้งหมดจะอยู่ในไฟล์:
   app/data/database.sqlite

เพียงคัดลอกไฟล์นี้ไฟล์เดียว ก็สามารถกู้ข้อมูลได้ทันที


-----------------------------------------------
5) ปัญหาที่พบบ่อย
-----------------------------------------------

1) โปรแกรมเปิดแล้วปิดทันที
   - อาจลบไฟล์หรือเปลี่ยนตำแหน่งโฟลเดอร์
   - ให้ตรวจว่าโฟลเดอร์ app ครบทุกส่วน

2) รูปภาพไม่แสดงในรายงาน PowerPoint
   - ตรวจว่ารูปถูกเก็บใน: app/uploads/
   - ตรวจว่าชื่อไฟล์ไม่มีตัวอักษรแปลก

3) เปิดหน้าเว็บไม่ได้
   - ตรวจว่าโปรแกรมกำลังรันอยู่
   - พิมพ์ใน browser:
        http://localhost:3000


-----------------------------------------------
6) ติดต่อผู้พัฒนาระบบ
-----------------------------------------------

CareerLens APP ถูกพัฒนาเพื่อใช้งานภายในองค์กร
และสามารถปรับแต่งเพิ่มเติมได้ตามต้องการ
